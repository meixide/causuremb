Algorithm Implementation for 'Causal Survival Embeddings'

This archive contains the source code for the algorithm described in the accompanying paper. To execute the algorithm, you only need to run the code in the main.R file.

Instructions for Running the Algorithm:

1. Make sure R is installed on your machine. If it's not, you can download it from R Official Website.

2. Extract the ZIP file and navigate to the directory containing main.R.

3. Open a terminal or R console and set it to the directory containing main.R.

4. Run the whole script. It creates an artificial dataset, performs cross-validation and displays the final estimator in a plot. Color code for the output is: observational k-m control arm in black, observational k-m control arm in blue, causal survival embedding in red.
